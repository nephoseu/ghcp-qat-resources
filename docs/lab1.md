# Lab 1  Getting Started with GitHub Copilot

## Overview

This exercise walks you through your first hands-on experience with GitHub Copilot inside GitHub Codespaces — no local setup required.

**Estimated time:** 30–45 minutes

---

## What you will do

- Install GitHub Copilot using GitHub Codespaces
- Prompt GitHub Copilot for code suggestions
- Accept code suggestions from GitHub Copilot

---

## Instructions

1. Select the button below to open the exercise on GitHub.
2. In the template repository, select **Start course** or **Use this template** to create your own copy. Use a **public repository** — private repositories consume GitHub Actions minutes.
3. After creating your repository, wait about 20 seconds and refresh the page.
4. Follow the instructions in the repository's **README** tab to complete the exercise.
5. When finished, return here for a knowledge check and your completion badge.

[Start the exercise on GitHub](https://github.com/skills/getting-started-with-github-copilot){ .md-button .md-button--primary }
