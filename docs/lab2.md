# Lab 2 Develop Unit Tests with GitHub Copilot

## Overview

In this exercise you use GitHub Copilot to accelerate writing unit tests for a C# application, using the Chat view and Agent mode in VS Code.

**Platform:** Microsoft Learn (hosted by Microsoft)  
**Estimated time:** 45–60 minutes

---

## What you will do

- Use the Chat view and Agent mode to create a new test class
- Use the Chat view and Agent mode to generate unit tests for a C# application
