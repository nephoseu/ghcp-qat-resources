# GitHub Copilot for QAT Labs

Welcome to the GitHub Copilot for QAT Training series. Each lab is a self-contained
hands-on exercise targeting a specific testing discipline.

## Labs

| Lab | Topic | Time |
|-----|-------|------|
| [Lab 1](lab1.md) | Getting Started with GitHub Copilot | 45 min |
| [Lab 2](lab2.md) | Develop Unit Tests with GitHub Copilot | 30 min |
| [Lab 3](lab3.md) | Selenium to Playwright Migration with GitHub Copilot | 60 min |
| [Lab 4](lab4.md) | Load & Performance Testing with JMeter using GitHub Copilot | 60 min |
| [Lab 5](lab5.md) | Generating Test Data & Building a Test Harness with GitHub Copilot| 45-60 min |


## Prerequisites

| Tool | Version | Download |
|------|---------|----------|
| Git | 2.48 or later | [git-scm.com](https://git-scm.com/install/source) |
| Python | 3.13 or later | [python.org](https://www.python.org/downloads/) |
| .NET SDK | 9.0 or later | [dotnet.microsoft.com](https://dotnet.microsoft.com/en-us/download) |
| Java | 8 or newer | [oracle.com](https://www.oracle.com/java/technologies/downloads/#jdk26-linux) |
| JMeter | 5.6.3 | [jmeter.apache.org](https://jmeter.apache.org/download_jmeter.cgi) or [Homebrew (macOS)](https://formulae.brew.sh/formula/jmeter) |
| Visual Studio Code | Latest | [code.visualstudio.com](https://code.visualstudio.com/download) |
| GitHub Copilot for VS Code | Latest | [Setup guide](https://code.visualstudio.com/docs/setup/copilot) |
| GitHub Copilot CLI | Latest | [github.com/features/copilot/cli](https://github.com/features/copilot/cli) |
