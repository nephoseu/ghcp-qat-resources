# QA Automation Training Labs

Welcome to the GitHub Copilot QA Automation Training series. Each lab is a self-contained
hands-on exercise targeting a specific testing discipline.

## Labs

| Lab | Topic | App under test | Time |
|-----|-------|----------------|------|
| [Lab 1](lab1.md) | Getting started with GitHub Copilot | GitHub Codespaces (hosted) | 30–45 min |
| [Lab 2](lab2.md) | Unit tests with GitHub Copilot | Microsoft Learn (hosted) | 45–60 min |
| [Lab 3](lab3.md) | Selenium → Playwright migration | TaskDesk (Django, port 8080) | 60–90 min |
| [Lab 4](lab4.md) | JMeter load testing | TaskDesk API (FastAPI, port 8081) | 60–90 min |
| [Lab 5](lab5.md) | pytest harness + test data generation | TaskDesk API (FastAPI, port 8081) | 60–90 min |

## Before you start

Download the app you need for your lab, then follow the setup steps inside.

[Get the apps](downloads.md){ .md-button .md-button--primary }

## Prerequisites

- Python 3.11+
- Git
- Java 8+ *(Lab 2 only — required by JMeter)*
- A browser with GitHub Copilot enabled
